# Repository Instructions

- The company and platform name is written exactly as `FLAMOX365`.
- The connector product name is written exactly as `Edge Connector`.
- Never combine both names into one product name.
- Keep publisher private keys, access tokens, generated `dist` directories and
  `.fmx` artifacts out of source control.
- Every extension declares the smallest possible capabilities, network targets
  and secret names and includes automated tests.
- Source code, classes, interfaces and types use domain names without brand
  prefixes.
