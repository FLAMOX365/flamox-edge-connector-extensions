# Support

Use
[GitHub issues](https://github.com/FLAMOX365/flamox-edge-connector-extensions/issues)
for reproducible extension defects, documentation gaps, and focused usage
questions. Search existing issues first and include the affected extension and
version, Edge Connector commit, Node.js version, device or protocol version,
minimal reproduction, and redacted logs where relevant.

Community support is provided on a best-effort basis and does not create a
service-level commitment. Contractual FLAMOX365 support remains governed by the
applicable customer agreement.

Do not report credentials, private configuration, customer data, or suspected
vulnerabilities in a public issue. Follow the [security policy](SECURITY.md) for
security-sensitive reports.
